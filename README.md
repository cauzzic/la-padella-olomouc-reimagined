# La Padella Olomouc Reimagined

DŮLEŽITÉ: Tento projekt je zcela nový a oddělený od původního webu La Padella. Nepřipojuj se k žádné existující databázi ani backendu původního projektu, neupravuj jeho zdrojový kód ani jeho nastavení. Prozatím vytvoř pouze nový web s ukázkovými daty. Databázi, administraci a ostatní backendové funkce budeme řešit později samostatně.
Vytvoř nový moderní web pro restauraci La Padella v Olomouci.

Jako referenci použij současný web https://lapadella.cz/. Prohlédni si jeho veřejnou část a pochop strukturu, obsah, funkce a způsob prezentace restaurace.

Důležité požadavky:

Nový web musí mít vlastní, originální vizuální styl a rozložení. Nekopíruj současný design jedna ku jedné.

Zachovej podobný rozsah a logiku webu restaurace, ale přizpůsob design nové pobočce v Olomouci.

Vytvoř kompletní responzivní veřejnou část webu pro počítače, tablety i mobily.

Připrav přehlednou úvodní stránku, jídelní lístek, sekci denního a týdenního menu, speciální nabídku, galerii, informace o restauraci, kontakty a rezervace.

Věnuj pozornost typografii, fotografiím jídel, přehledné navigaci a profesionálnímu vzhledu.

Použij realistický ukázkový obsah, který bude možné později jednoduše nahradit skutečnými údaji olomoucké pobočky.

Projekt musí být připravený na pozdější napojení databáze a administrace pro správu jídel, cen, fotografií, týdenního menu, speciálních nabídek a alergenů.

Zatím se soustřeď především na veřejnou část webu a kvalitní design. Nevytvářej zbytečně složitý backend ani nepřipojuj databázi původní restaurace.

Architekturu navrhni tak, aby bylo možné později doplnit samostatnou administraci a samostatnou databázi pro olomouckou pobočku.

Nejdříve si promysli celkovou strukturu webu a potom vytvoř jeho kompletní první verzi. Nejde pouze o jednoduchou úvodní stránku, ale o ucelený web restaurace.
